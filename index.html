非商业同人 · 开发中 / Fan project

一个关于信仰、禁忌与被封存真相的同人游戏企划。故事发生在政教合一的摩德纳，一个仍以冷兵器与简单火器为主的国家。

Fan project / 同人企划本作基于《重返未来：1999》世界观创作，是非商业同人游戏作品。

沙漠尽头，边界之上，
一座要塞正在替两个国家保守秘密。

拉普拉要塞位于摩德纳边境、沙漠边缘，是通往邻国海特洛的枢纽。而在城墙投下的阴影里，极端宗教组织“重塑之手”已经渗透进来。他们反对大主教与人类妥协的政策，掌握着与“暴雨免疫术式”相关的禁忌技术。

这是一部关于信仰如何被权力雕刻、真相如何被共同沉默的作品。

The studio / 03 关于我们

把世界做深，
再把故事放进去。

武汉米格雷纳网络（MigrainE）是一间立足武汉的独立游戏工作室。

我们以世界观叙事为核心，试图让地理、信仰与权力关系自己长出故事。比起解释一个世界，我们更在意让人物在制度的缝隙里做出选择，并让选择留下代价。

目前，工作室正在构筑《拉普拉要塞：边界暗影》的世界、人物与叙事原型。
